==============================================================================
RESUME DATASET DIRECTORY
==============================================================================

Project: Resume Mining and Classification System
Kaggle Dataset: https://www.kaggle.com/datasets/hadikp/resume-data-pdf
Total PDFs: ~8,905 Resume PDFs organized into Category Folders.

DIRECTORY STRUCTURE:
data/
  ├── README.txt                     <- (This file)
  ├── resume_dataset.csv             <- Generated by training/preprocess.py via OCR
  └── Resumes PDF/                   <- Place your downloaded Kaggle dataset here
        ├── Public Relations resumes/
        ├── React Developer resumes/
        ├── Java Developer resumes/
        └── [other category folders]/

HOW TO PROCESS:
1. Extract your Kaggle download into:
   data/Resumes PDF/

2. Run the OCR batch extraction pipeline:
   python training/preprocess.py

3. This generates:
   data/resume_dataset.csv

The script processes resumes in batches, skips already processed resumes,
saves checkpoints periodically, and handles corrupted PDFs gracefully without crashing.
