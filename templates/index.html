 How It Works

                    
The 4-stage end-to-end Data Mining and Machine Learning pipeline

                

                

                    

                        
01

                        

                        
Upload Resume

                        
User uploads a resume PDF (supports both scanned image-based and digital documents).

                    

                    

                        
02

                        

                        
Extract Resume Text

                        
PDF pages are converted into images and processed through Tesseract OCR to extract complete text.

                    

                    

                        
03

                        

                        
Mine & Preprocess Data

                        
Text is cleaned, normalized, stopwords are filtered, and candidate skills are mined using taxonomy search.

                    

                    

                        
04

                        

                        
Predict Category

                        
TF-IDF features are extracted and fed into the trained Machine Learning classifier to output the job category.

 About the Project

                    
Academic concept explanations designed for B.Tech Computer Science presentation

                


                

                    

                        

                        
What is Resume Mining?

                        

                            Resume Mining is the specialized application of text mining and natural language processing to extract structured information (skills, qualifications, contact records) from unstructured resumes and classify them into professional career domains.
                        

                    


                    

                        

                        
How Data Mining is used?

                        

                            Data Mining discovers hidden linguistic patterns and feature correlations across thousands of resumes. By converting unstructured documents into numerical feature representations, algorithms can detect distinctive domain terminology.
                        

                    


                    

                        

                        
How OCR is used?

                        

                            The Kaggle dataset contains scanned, image-based PDFs where traditional text extractors yield 0 characters. Optical Character Recognition (OCR) via pdf2image and Tesseract OCR renders the PDF pages to high-resolution images and converts pixel patterns into machine-encoded text.
                        

                    


                    

                        

                        
How TF-IDF is used?

                        

                            Term Frequency - Inverse Document Frequency (TF-IDF) scores words by how frequently they appear in a resume balanced against how common they are across the entire 8,905 dataset, giving high mathematical weights to domain-specific keywords (e.g. "Kubernetes", "PyTorch").
                        

                    


                    

                        

                        
How Machine Learning Classification works?

                        

                            Supervised classification algorithms (such as Logistic Regression and Linear SVM) learn decision boundaries across high-dimensional TF-IDF feature vectors. The model maps extracted vocabulary distributions to category probabilities, predicting the candidate's best matching job profile with quantitative confidence.
